- 开始时 lint、typecheck、45 unit、迁移检查、27 PostgreSQL integration 全通过。原 PROJECT_STATUS、V1.1-B 报告修改及未跟踪运维/研究文件保留，不混入本次提交。
- 机会匹配复用原四态资格引擎、规则版本、个人钱包/活动/批次；只读取已审核发布、有官方核实来源且当前有效的正式活动。自然语言和雷达原文不会成为执行条件或权限。
- 确定性排序展示分项；卡片解释已满足、未满足、未知信息、期限、下一步、官方来源和规则版本。支持资格、会员、截止窗口、可计算性与价值排序。

- 站内提醒覆盖报名、消费、入住、领取、积分到期、待办逾期和正式规则变化；支持待处理、已读、完成、忽略、稍后，数据库唯一键和 Owner 行锁保证去重与并发幂等。
- `/me` 为每日私人决策首页；原 V1 操作页保留在 `/me/records`。公共首页、发现和计算器继续可访问。
- 迁移 `0008_youthful_forge.sql` 只新增个人条件与提醒表。`db:generate` 再次执行显示没有 schema 差异，没有改写原账本或 A/B 表。

完整数据流、字段规范、分值和时间边界见 [架构说明](./v1.1-c-architecture.md)。

## 限制与后续

- C 没有依赖 AI Key；B 的真实文本/图片识别仍为 BLOCKED，未宣称已验收。
- 现有纯文本活动需管理员按真实官方条款补充完整结构化条件；个人会员、卡种、消费和入住记录仍是人工登记，未连接官方账户核验。

- 未 push、未部署、未连接或修改生产、VPS、nginx、SSH 或 Blue Room。生产迁移与发布未授权。
