## 交付功能与联动

- `/me` 复用 Auth.js 管理员作为唯一真实 Owner，管理会员计划、未知等级、等级/积分人工日期、券与权益、联名卡持有状态、备注和核对日期。等级/卡状态的已知条件核对读取最新 Wallet，不推断完整活动资格，也不声称官方账户验证。
- 积分按批次记录期初余额、住宿、活动奖励、信用卡、其他来源和调整。提供到账、兑换、到期确认、正负调整、批次余额、完整流水和未来 30 天到期提示。
- 已发布活动详情支持按周期收藏或加入计划；进度、预计与实际奖励、达标说明、领取/到账时间和版本关联均在私人 Action 内。重复点击不会覆盖已有进度。
- 活动页展示报名、预订、住宿/消费、达标、领奖和检查到账等适用任务草稿；必须选择并显式确认后创建。已知基础日期默认“规则推算”，不自动把节假日顺延窗口标为官方最终日期。个人待办不会因公共活动结束删除；也支持关联批次的人工到期使用待办。
- Owner 确认奖励实际到账后，活动状态、批次、流水和 acquired 收益记录在同一事务内保存。每个参与周期只允许一笔积分奖励到账；另一真实周期可独立记录。
- 三类计算器保留 Phase 4 无状态计算，增加显式保存。快照保存输入、报价时间/来源、估值、公式、关联公开活动/规则/证据、计算结果、假设、未确认项和当时会员资料。手动报价比较没有外部规则时明确记录“人工输入/无外部规则”。
- 历史方案只能修改名称/备注或删除；重算通过会话存储回填原始输入，读取当前公开关联依据，需重新核对资格，再保存为独立新方案。旧规则、旧会员快照与结果不被改写。
- 积分兑换与兑现共用一个原子入口，同时扣积分和创建收益记录；纯现金优惠可用 0 积分登记。现金金额必须注明比较依据，无可比较现金基准时保留为空。

## 余额、幂等和事务

可用积分＝未到期批次剩余积分合计。未知到期日和有证据永不过期是不同状态；不会套用统一锦江积分有效期。已知到期时立即排除在可兑换余额之外，Owner 的“确认到期”补记到期流水。全部批次剩余量＝signed 流水合计；尚未补记的过期积分另列，便于核对。

所有账目写入先锁定 Owner 行，再按固定顺序处理钱包/活动/批次，避免并发超扣和死锁。兑换按到期时间优先、到账时间和 ID 排序，对可用批次 `FOR UPDATE` 后扣减，流水记录每批 delta 和 remainingAfter。余额不足或任一步失败时，批次、流水与收益一起回滚。数据库非负检查为第二道防线。

Owner+幂等键唯一约束和规范化请求 SHA-256 摘要共同校验重试；同键不同请求拒绝。奖励还有 Owner+Action 的部分唯一索引，防止换键重复确认同一周期。UI 防双击，未确认请求键在会话存储保留，刷新后可重试；业务关联和数据库约束仍是最终防护。人工调整新增 signed 流水和审计，不覆盖历史。

## 收益口径

1. 预计收益只来自未到账的个人参与预计字段，不生成积分批次，不加入实际现金。
2. 当前可用积分与累计获得积分分别展示；兑换、到期和人工调整单独保留。权益券通过 Wallet 持有/使用日期管理。
3. 已证明现金节省仅合计 realized.cashMinor；没有可比较现金基准时不猜金额。
4. 综合经济价值（微元）＝（现金节省分 − 参与成本分 − 放弃权益分）×10000 − 已消耗积分×每分估值微元。现金基准、积分估值或必要成本字段未知时不输出完整合计。

例如奖励到账 8000 分，只增加资产；随后兑换抵扣 160 元，现金节省仍为 160 元，绝不累计成 320 元。若估值 0.02 元/分、额外成本 10 元、放弃权益 5 元，则综合经济价值为 −15 元。集成测试对这组数值做精确 bigint 断言。

每笔兑现关联具体积分流水或人工现金依据，收益页同时展示现金/成本、积分机会成本与记录 ID。此视图不是自动银行对账或复杂会计系统。

## 隐私与安全

- 所有私人页面和 API 均服务端认证；未登录与无效会话不返回个人记录。没有公开注册、社交登录、锦江账户密码、银行卡号/CVV/银行凭据。
- 写 API 在认证后检查实际请求 Host、协议、Origin 或同源 Fetch Metadata；跨站请求返回 403。Auth.js 原有登录 CSRF 与管理审核/发布权限保持。
- 个人 API 使用 `Cache-Control: private, no-store` 与 noindex，个人页元数据为固定文案；公开 DTO 不查询私人表，活动公开页只获取认证布尔值显示入口。
- 会员/活动/任务/历史字段按纯文本渲染；XSS 字符串不会执行。数据库失败响应不返回 SQL、参数或连接信息。
- 未实现数据导出；备份存本地私有目录，不在公共静态路径或 Git 中。

## 限制与风险

- V1 人工登记和核对，无官方账号同步、自动报名/领奖/预订、价格爬虫、AI Agent、推送、支付、银行卡绑定或公开多用户注册。
- 站内提示仅在打开网站时可见；关闭网站不会通知。
- 只具体支持锦江荟展示；数据结构有 Owner/Program 隔离，但没有完整多租户管理或用户数据导出。
- 历史重算保留原始手动报价参数，不会自动抓新价格或从自由文本推断新活动门槛。需 Owner 核对参数与新证据后保存。
- 现金基准、积分估值和成本由 Owner 人工提供；综合价值是记录口径，不是官方回报保证。
- Owner 行锁优先保障自用正确性；大规模多用户吞吐优化不在本阶段。开发服务器在浏览器页面关闭或刷新取消流时可能输出 destination stream 日志；本地生产构建通过，未把生产服务器运行验证作为本次部署结果。
