# TravelWise V1.1-A 验收报告

验收分支：`codex/v1.1`  · 基线：`f2c85d1`  · 范围：优惠雷达与来源监控。

## 交付

- 管理员 `/admin/radar`：来源登记、频率、暂停/恢复、手动检查、状态和错误信息。
- `monitor_sources`、`monitor_versions`、`monitor_runs`、`radar_events` 四张迁移表；来源复用 `programs` 和既有 `evidence`/`promotions` 链路。
- 公开网页/RSS/Atom 文本规范化、SHA-256 指纹、ETag/Last-Modified、响应大小/超时/重定向限制、正文区域选择器、条款变化 Diff。
- 首次检查基线、无变化去重、实质条款变化待审核、忽略/确认/重复状态；不自动发布。
- `scripts/radar-runner.ts` 与 `npm run radar:run`，支持一次执行和 `--watch`，并发上限 2、三次退避重试、单来源故障隔离。
- 管理入口与原有 Auth.js、审计、发布状态保持服务端权限隔离。
